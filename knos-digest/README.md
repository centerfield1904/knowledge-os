# knos-digest

Generated persona digest markdown output.

Digest files are committed by the morning ingest wrapper so the `bvaibhav-info`
GitHub Action can publish them to the website.

## Format

**Filename:** `YYYY-MM-DD.md`  
**Content:** Canonical persona-marked digest exported to website JSON

## Structure

Each file contains persona sections and selected stories from HN/RSS sources.
WhatsApp delivery sends a persona-filtered website link for the relevant date.

## Usage

**View digest:**
```bash
cat 2026-02-20.md
```

**Search across digests:**
```bash
grep -r "AI agent" .
```

## Archive Stats

```bash
# Total digests
ls -1 *.md | wc -l

# Digests with Substack items
grep -l "📰" *.md | wc -l
```
